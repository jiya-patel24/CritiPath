Route Finding

Compute optimal paths using C++ algorithms

Finds the closest node marked as a Target by fewest steps (BFS). Target nodes are rendered as squares.

Select parameters and click "Find Route" to execute analysis on the C++ engine.

Network Vulnerabilities

Evaluate edge closures and articulation points

Runs Tarjan's DFS-based analysis to detect single points of failure: Articulation Points (nodes) and Bridges (edges) whose removal disconnects graph components.

Calculates how many OTHER nodes lose connectivity to the reference node if the failing node is removed.

Choose an analysis to run on the network.
